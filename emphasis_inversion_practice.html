Adding Emphasis — Practice

Instructions: Rewrite each sentence to add emphasis. Keep the same meaning. In the box, write the complete sentence — from the first word to the last, including any words that are given — and press Check.

The exercise comes in sets of three. The three sentences in a set work the same way, but you get less help each time: first the beginning of the answer, then only the first word, then nothing.

⚠ Remember: invert only after a negative or limiting expression at the start of the clause. After but, use normal word order.
