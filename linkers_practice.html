Using Linkers — Practice

Instructions: Rewrite each sentence using the linker shown. Keep the same meaning. In the box, write the complete sentence — from the first word to the last, including any words that are given — and press Check.

The exercise comes in sets of three. The three sentences in a set work the same way, but you get less help each time: first the beginning of the answer, then only the first word, then nothing.

⚠ Remember: check what comes after the linker — a clause, a noun / -ing, a base verb, or a new sentence with a comma. Change the grammar when you change the linker.
