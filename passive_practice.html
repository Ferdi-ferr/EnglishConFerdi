The Passive — Practice

Instructions: Rewrite each sentence using a passive or causative form. Keep the same meaning. In the box, write the complete sentence — from the first word to the last, including any words that are given — and press Check.

The exercise comes in sets of three. The three sentences in a set work the same way, but you get less help each time: first the beginning of the answer, then only the first word, then nothing.

⚠ Remember: be / get + past participle (broken, not broke). In causatives, the object comes before the participle.
